Music Management

A full stack app. Using Angular JS with TypeScript to build the frontEnd, hosting in Node. APIs to get data from backend in .Net. MySql as a BDMS. In this project Material Design for components was used. This app allows to achieve CRUD of mains entities like Bands, Songs, Albums and Singers. An user authentication management, too.

Meli Products

A search-buy product app. Created using Swift, SwiftUI and Rest API. An App where you can find product and see its detail, in a huge catalog. The user can search and view the detail of a particular product. The technology used are SwiftUI as a visual framework and MV as an architecture pattern.

GameStream

iOS app created following two of the Platzi's courses. Built using SwiftUI, UserDefaults, API REST, AVkit and third party libraries. With the goal of get it done in code with SwiftUI Apple's library. This is to practice both Platzi's online courses. In this app, you can find videos about videogame's digital content. Also, you can share your reviews and vote for your favourites videogames.

languageClosureCalculatorApp

You can add 4 chains, and toggle if you want a common "closure" or a positive "closure", about one "language". After that, you just tap over RUN button. It will be display the result below and a text field in case you want to select part of it. Also, you have got a COPY button, to save in device's clipboard all the result.
